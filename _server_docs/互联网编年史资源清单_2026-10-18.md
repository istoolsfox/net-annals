# 互联网编年史资源清单（全球 + 中文）

> 整理日期：2026-10-18
> 目的：收集"编年史"式互联网历史资源——尽量细到每一条、每一个月、每一天发生了什么（国家大事、网民生活、社会事件、小产品小文化），覆盖全球互联网与中文互联网两侧。
> 结论先行：**精确到日的成文编年史没有单品**，全球侧有 Hobbes 时间线等"事件级"年表；中文侧的网民生活史需要用"维基逐日存档 + 热搜归档 + 流行语编年 + 社区兴衰文章"几层原料拼装。

## 三、逐日粒度原料（编"网民生活史/社会史"用）

> 这是回答"哪一天，国家/社会/网民发生了什么"的核心原料层。

### 全球侧
1. **ACM On This Day in Computing History**——计算机/互联网史"历史上的今天"逐日档案：
   https://www.acm.org/education/otd-in-computing-history
2. **BBC On This Day**——按日期组织的历史新闻档案（1997—2005 时代站型）：
   https://www.bbc.co.uk/onthisday
3. **Hacker News 按日期搜索**——2007 年以来全球技术社区每一天在讨论什么，逐日粒度最完整的社区记忆：

   https://www.webdesignmuseum.org

   https://doodles.google

- **Wayback Machine（互联网档案馆）**：任意网站、任意历史日期的页面快照，终极"逐日"原料。
  https://web.archive.org

## 五、拼装思路（自制成文编年史）

要得到"某年某月某日，国家/社会/网民发生了什么"的成文编年史，可按三层叠加：
1. **骨架层**：维基《新闻动态》逐日存档 + 官方大事记（国家/社会/行业大事）
2. **血肉层**：热搜归档（网民当天在看什么）+ Hacker News（全球技术圈当天在聊什么）
3. **情绪层**：年度流行语榜单 + 社区兴衰文章（当年的语言、人物、社区氛围）

## 六、粒度对照速查

| 想查什么 | 用什么 |
| --- | --- |
| 某天全球/中国大事 | 维基《新闻动态》逐日存档（zh/en） |
| 某天网民在看什么 | justjavac 热搜归档（2020-11 起逐日） |
| 某年社会情绪 | 《咬文嚼字》年度十大流行语 |
| 某天技术圈在聊什么 | hn.algolia.com 按日期搜 |
| 某年互联网基础大事 | Hobbes' Timeline / CNNIC 大事记 |
| 某年网站长什么样 | Web Design Museum / Wayback Machine |
| 某个经典事件（贾君鹏/3Q 大战等）的具体日期 | 维基事件条目 + 社区兴衰文章 |
