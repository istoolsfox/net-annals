## 二、市级源（P1 主力）

1. **市政府官网「大事记/市志」栏目**：多数地级市政府门户设大事记栏目（如 hangzhou.gov.cn）。逐省建域名清单后接入 n8n 工作流 B。
2. **人民网/新华网地方频道**：地方频道按省组织，近年事件源。
3. **维基「XX市」词条大事记段**：骨架提取用。

## 三、县级源（P2 主力）

1. **县政府工作报告**（每年 1-2 月发布）：含上年实事清单，天然一县一年 10-12 条骨架；县政府门户多为 `<县名拼音>.gov.cn` 或挂地级市门户下。
2. **县融媒体公众号**：源散，重点县先行。
3. **上市公司注册地映射**：`scripts/geo_regloc.py`（新浪公司资料页，办公/注册地址 → 市/县码）。实测：宁德时代→蕉城区+宁德市、金山办公→海淀区。已知限制：北交所码（8xxxxx/43xxxx）新浪无页，需另源。
4. **中国县域经济报**：可访问性待实测。

## 四、结构化源（低风险高产出）

1. **民政部区划调整公告**（撤县设区/设市）：每年全量、精确到日，全库合规。
2. **cninfo 公告**（`scripts/cninfo_announcements.py` 已有）：上市公告书 T-1 规律可做城市产业事件。
3. **USGS 地震目录 / LL2 发射库**：已接入 GAP_FINDER 台账。

## 五、接入节奏建议

- P1 城市批：先用 Agent+检索（本轮已跑通），方志网收割器列入 n8n 工作流 B 扩展项（先 3 市最小闭环）。
- P2 县级批：政府工作报告批处理是产能关键（一县一年 10-12 条），值得做成专用收割器。

## 六、市级大事记栏目实测（C10，2026-11-04）

`scripts/city_chronicle.py`（搜狗 gov.cn 直抽 + 大事记特征验证，同 county_gov_report 模式）3 市试点：

| 市 | 结果 | 说明 |
|---|---|---|
| 庆阳 | ✅ 全文页 | 市政府公报内大事记静态可达（zgqingyang.gov.cn/gk/zfxxgk/zfgb…）；内容偏会议纪要，提取需按「建设/开通/成立」事件行加权、会议类降权 |
| 天水 | ✗ | 门户无公开静态大事记栏目，搜到均为党史编纂新闻 |
| 宝鸡 | ✗ | 民政局 col 栏目 JS 渲染，urllib 直抓 0 事件行 |

结论：市级「大事记」栏目静态直抓命中率约 1/3，命中内容质量偏会议纪要——**n8n 大事记子流降级为逐市探测命中才进线的补充通道**；市侧主力仍是 Agent 检索批次（C10 性价低于 C9 县侧收割器）。n8n 挂接前置：在 n8n 工作流卡片开启 MCP 访问（现「编年史·新闻采集」EOFcQB3xOcW8ih3r 未开放，无 REST API key），开启后可直接消费 `data/derived/city_chronicle_probe.json` 的 verified 队列。
