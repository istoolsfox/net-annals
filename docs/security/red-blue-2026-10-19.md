# 红蓝对抗报告 · net-annals 站点（2026-10-19）

> 授权：项目所有者本人要求对本项目（自有服务器 toolsfox.top）做红蓝对抗与 bug 排查。
> 范围：静态站点（site/）、数据管线（scripts/）、nginx 配置、数据内容。

## 一、攻击面分析

静态站 + 数据管线。无后端 API、无用户输入入库、无第三方脚本（v2 已移除 three.js，全站唯一 JS 是自己的 app.js）。
主要攻击面：① 数据内容投毒 → DOM XSS；② 供应链；③ nginx 配置；④ 管线健壮性（Agent 产出的脏数据）。

## 二、红队战果（攻击）

| # | 攻击向 | 手段 | 结果 |
| --- | --- | --- | --- |
| R1 | 数据投毒 DOM XSS | 全库 903+ 条 × 6 字段 × 11 种载荷模式（script/onerror/javascript:/img/svg/iframe/eval/data:…）自动扫描 | ✅ 零命中——数据源为维基/官媒/官方博客，且 build 门禁拦截非 http(s) URL |
| R2 | 协议逃逸 | 检查 `javascript:`/`data:text/html` 形式来源链接 | ✅ 门禁 `startswith('http')` 全拦 |
| R3 | 模板转义审计 | 枚举 app.js 全部 innerHTML 赋值点（9 处）与模板插值（36 处），逐一核对是否经过 esc() | ✅ 未走 esc 的 17 处均为常量/数字/白名单字段；esc() 覆盖 title/detail/impact/aftermath/sources 等 |
| R4 | 响应头侦察 | curl -I 线上站点 | ⚠️ 发现缺 CSP / X-Frame-Options / Referrer-Policy / Permissions-Policy → 蓝队修复（见 B2） |
| R5 | 路径遍历/敏感路径 | --path-as-is 遍历、不存在路径、data.json 直取 | ✅ 遍历被规范化、404 正常、data.json 公开属设计预期 |
| R6 | 竞态攻击 | D3 Agent 增量写盘期间并发构建 | ⚠️ 构建失败（fail-closed，符合预期）；教训：**只在批次完成通知后构建**，已写入 PROGRESS |

## 三、蓝队修复（防御）

| # | 修复 | 说明 |
| --- | --- | --- |
| B1 | `safeUrl()` 运行时净化 | 卡片 href 只放行 http(s)，即使门禁被绕过也不产生 javascript: 链接（纵深防御） |
| B2 | nginx 安全头全套 | CSP（default-src 'none'; script-src 'self'; frame-ancestors 'none'…）、X-Frame-Options DENY、Referrer-Policy、Permissions-Policy；配置已备份，nginx -t 通过后 reload，线上复验五头齐活 |
| B3 | jumpTo boot 门闸 | 数据未加载完点击时代跳转被静默吞掉 → 排队机制，boot 完成后 flushPending 执行（极端竞态复现测试通过：DOM 就绪即点，最终 scrollY=69896 正确落点） |
| B4 | 跳转落点动态偏移 | 写死 128px → 动态测量工具栏高度（v3 工具栏三行高 ~230px，时代头曾被压在下面） |
| B5 | 视口内卡片立即置亮 | reveal 动画曾依赖 IO 回调，瞬时跳转后有"空侧翼"窗口 → 渲染时对视口内卡片 rAF 立即加 .in |
| B6 | expandAll 状态持久化 | 「全部展开」此前只影响已渲染卡片，懒渲染后新卡片仍是收起态 → UIState 统一管理并在渲染时应用 |

## 四、功能性 bug（非安全）顺带清单

1. eraIndex 越界钳制（2026 下半年事件曾被静默丢弃）
2. 时代胶囊年份取真实数据 min–max（曾显示虚构"2027"）
3. 当前时代高亮阈值 200→280px
4. 语义级查重规则（同日标题重叠>60%）固化进 dedup 管线
5. normalize.py：畸形日期（1990-1001）/短 id 自动修复 + import 补全

## 五、回归验证

- 最远时代跳转（era-0 → era-7）：瞬时落点、390 卡全渲染、时代头完整露出 ✅
- 极端竞态（DOM 就绪即点击跳转）：门闸排队、boot 后正确执行 ✅
- CSP 上线后功能回归：跳转/展开/搜索/主题全正常，零违规事件 ✅
- 双主题、移动端视口（390×844）抽查 ✅

## 六、遗留与建议

- check_urls.py 对 429/403 的"容忍"可能掩盖真死链 → M2 复核轮换 UA/延迟重试
- 截图验收时遇到 IAB 合成器陈旧帧 → 以 DOM 探测（getBoundingClientRect + computedStyle）为准，截图仅辅助
- 数据量到万级时引入虚拟滚动（当前全量渲染 900-2000 条实测无压力）
